Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown": a blind judge compares two job titles and picks the weirder, funnier one. Our title is **"Senior Vice President of Apologizing to Geese"** — a perfectly real-sounding corporate role with one gloriously odd twist.

## Run it

```sh
python3 main.py
```

Running it writes the single job title to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.
